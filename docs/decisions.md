# 결정 로그

덧붙이기만 한다. 지난 줄은 고치지 않는다. 결정이 바뀌면 새 줄을 쓰고, 옛 줄의 "상태"에 `→ #N`만 단다.
현재 규칙의 원본은 `docs/architecture.md`다. 여기는 언제·누가·왜만 적는다.

정한 사람: **사람**(직접 고름) / **위임**(사람이 AI 추천을 "추천대로"로 받음, `explain-log.md` 대기) / **AI**(세부 설계, 사람은 사후에 봄)
